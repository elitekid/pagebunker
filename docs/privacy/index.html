PageBunker Privacy Policy

PageBunker 개인정보 처리방침

Last updated: 2026-09-17

최종 수정일: 2026-09-17

Summary

PageBunker does not collect, transmit, or sell any personal data. It has no sign-up, no account, and no server. It contains no analytics, advertising, or tracking code.

Data we collect

None. No data is sent to the developer.

Data stored on your device

PageBunker keeps the following only on your device:

  • Saved articles: title, author, publish date, body, and link
  • Tags, reading positions, read status, and library state (To read, Read, Archive, Trash)
  • Settings
  • The 3 most recent backup copies, stored inside the browser
  • Backup files in the PageBunker folder in your Downloads folder: pagebunker-latest.json and dated files (up to the latest 7)
  • Files you choose to export (HTML or Markdown)

Articles in Trash are deleted automatically after 30 days. Removing the extension removes the data stored inside the browser. Backup and export files in your Downloads folder are ordinary files and stay until you delete them.

Network requests

The extension makes no network requests on its own. When you save an article, it reads the page that is already open in your tab.

A request goes to a website only when you:

  • Open the original page of a saved article
  • Load images for an article, or turn on image loading in settings

These requests go directly from your browser to that website. Images are not loaded by default.

Permissions

PermissionWhy it is used
activeTabReads the article only in the tab where you use PageBunker
scriptingRuns the article extraction code in that tab
storageStores saved articles and settings in the browser
unlimitedStorageLets a large library be stored without hitting the default quota
downloadsWrites backup files and export files
alarmsSchedules backups and cleans up the trash
contextMenusAdds the right-click menu item for saving
offscreenBuilds large backup files (Chrome and Edge only)

PageBunker does not request host permissions (access to all websites).

Changes

If this policy changes, the date at the top of this page will be updated.

요약

PageBunker는 개인정보를 수집하거나 전송하거나 판매하지 않습니다. 가입, 계정, 서버가 없습니다. 분석, 광고, 추적 코드도 없습니다.

수집하는 데이터

없습니다. 개발자에게 보내는 데이터가 없습니다.

기기에 저장되는 데이터

PageBunker는 다음 데이터를 사용자의 기기에만 저장합니다.

  • 저장한 글: 제목, 작성자, 게시일, 본문, 링크
  • 태그, 읽던 위치, 읽음 여부, 보관함 상태(읽을 글, 읽은 글, 보관, 휴지통)
  • 설정
  • 브라우저 안에 보관하는 최근 백업 사본 3개
  • 다운로드 폴더 안 PageBunker 폴더의 백업 파일: pagebunker-latest.json과 날짜가 붙은 파일(최근 7개까지)
  • 사용자가 직접 내보낸 파일(HTML 또는 마크다운)

휴지통의 글은 30일 후 자동으로 삭제됩니다. 확장을 삭제하면 브라우저 안에 저장된 데이터가 지워집니다. 다운로드 폴더의 백업 파일과 내보낸 파일은 일반 파일이므로 사용자가 지울 때까지 남아 있습니다.

네트워크 요청

확장이 스스로 보내는 네트워크 요청은 없습니다. 글을 저장할 때는 탭에 이미 열려 있는 페이지를 읽습니다.

다음 경우에만 해당 웹사이트에 요청합니다.

  • 저장한 글의 원문을 열 때
  • 글에서 이미지 보기를 누르거나, 설정에서 이미지 불러오기를 켤 때

이 요청은 사용자의 브라우저에서 해당 웹사이트로 직접 전송됩니다. 이미지는 기본으로 불러오지 않습니다.

권한

권한사용 목적
activeTabPageBunker를 사용한 탭의 글만 읽습니다
scripting그 탭에서 본문 추출 코드를 실행합니다
storage저장한 글과 설정을 브라우저에 보관합니다
unlimitedStorage글이 많아져도 기본 저장 용량 제한에 막히지 않게 합니다
downloads백업 파일과 내보내기 파일을 씁니다
alarms백업을 예약하고 휴지통을 정리합니다
contextMenus저장용 우클릭 메뉴 항목을 추가합니다
offscreen큰 백업 파일을 만듭니다(크롬·엣지만 해당)

모든 사이트에 접근하는 권한(host permissions)은 요청하지 않습니다.

변경

이 방침이 바뀌면 위의 최종 수정일을 갱신합니다.
